#### История и авторы алгоритма MSER

Алгоритм MSER (Maximally Stable Extremal Regions) был предложен Матушем Матейкой и Джереми М. Максаном в 2002 году. Этот метод был разработан для выделения стабильных областей на изображении, которые остаются неизменными в широком диапазоне пороговых значений. MSER нашел широкое применение в задачах компьютерного зрения, таких как распознавание объектов, отслеживание и сегментация изображений.

#### Описание и этапы работы алгоритма MSER

MSER — это алгоритм для выделения областей изображения, которые остаются стабильными при изменении порога. Алгоритм состоит из следующих этапов:

1. **Пороговая сегментация**:
   Изображение многократно сегментируется при различных порогах. Для каждого порога определяются связные компоненты. Связанная компонента — это множество пикселей, которые соединены друг с другом и имеют одинаковое значение интенсивности.

   Формула для пороговой сегментации:
   \[
   I_T(x, y) = 
   \begin{cases} 
   1 & \text{если } I(x, y) \ge T \\
   0 & \text{если } I(x, y) < T 
   \end{cases}
   \]

2. **Экстремальные области**:
   Экстремальная область — это связная компонента, которая либо полностью темнее (темная область на светлом фоне), либо полностью светлее (светлая область на темном фоне), чем ее окружение.

   Связанная компонента \( C \) при пороге \( T \) считается экстремальной областью, если:
   \[
   \forall (x, y) \in C \quad \forall (x', y') \in \partial C \quad I(x, y) < I(x', y')
   \]
   где \( \partial C \) — граница области \( C \).

3. **Стабильность областей**:
   Стабильность области определяется по изменению ее размера при изменении порога. Область считается максимально стабильной, если изменение ее размера минимально при изменении порога.

   Формула для определения стабильности области:
   \[
   \Delta(C) = \frac{|C_{T+\Delta T}| - |C_T|}{\Delta T}
   \]
   где \(|C_T|\) — размер компоненты \(C\) при пороге \(T\).

4. **Выбор максимальных стабильных областей**:
   Области, которые остаются стабильными в широком диапазоне порогов, выбираются в качестве конечных регионов.

#### Использование MSER в OpenCV

В библиотеке OpenCV алгоритм MSER реализован в классе `cv2.MSER`. Пороговые значения и параметры можно настроить при создании объекта MSER. Например:

```python
mser = cv2.MSER_create(_min_area, _max_area, _max_variation, _min_diversity, _delta, _max_evolution, _area_threshold, _min_margin, _edge_blur_size)
```

- `_min_area` и `_max_area` задают минимальный и максимальный размер областей.
- `_max_variation` определяет максимально допустимое изменение области.
- `_delta` — шаг изменения порога.

Пример создания объекта MSER:

```python
mser = cv2.MSER_create(min_area=60, max_area=14400, max_variation=0.25, delta=5)
```

#### Применение MSER в Корпусе

В Корпусе рукописного наследия Древней Руси алгоритм MSER используется для предварительной сегментации символов на изображениях. Этот процесс включает следующие шаги:

1. **Конвертация изображения в градации серого** (если изображение цветное):
   ```python
   gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
   ```

2. **Выделение регионов MSER**:
   ```python
   regions, bboxes = mser.detectRegions(gray)
   ```

3. **Создание маски и выделение контуров**:
   ```python
   mask = np.zeros_like(gray, dtype=np.uint8)
   for region in regions:
       for x, y in region:

       region_contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
       mask.fill(0)
   ```

4. **Фильтрация вложенных областей**:
   Алгоритм исключает вложенные области, чтобы избежать дублирования и пересечений.

5. **Отрисовка контуров на изображении**:
   ```python
   res_img = image.copy()
   ```

#### Преимущества и недостатки MSER

**Преимущества**:
- Независимость от масштаба: MSER эффективно выделяет области при изменении масштаба изображения.
- Робастность к освещению: Метод хорошо работает в условиях изменяющегося освещения.
- Высокая производительность: MSER работает быстро и эффективно для многих приложений.

**Недостатки**:
- Чувствительность к шуму: Алгоритм может выделять ложные области в присутствии значительного шума.
- Проблемы с текстурированными фонами: На текстурированных изображениях может выделяться много ненужных областей.

### Признаки изображения

После сегментации изображения на устойчивые области, по каждой выделенной области собираются следующие признаки:

#### 1. Моменты изображения

**Моменты изображения (moments)** — это количественные характеристики, которые описывают распределение пикселей в области. Они могут использоваться для вычисления различных свойств объекта, таких как площадь, центр тяжести и инерционные характеристики. Моменты до второго порядка часто используются для описания базовых свойств изображения.

Формула для вычисления геометрических моментов \( m_{pq} \):

\[ m_{pq} = \sum_{x}\sum_{y} x^p y^q I(x, y) \]

где \( I(x, y) \) — интенсивность пикселя в точке \((x, y)\).

Используются для:
- Оценки площади объекта.
- Нахождения центра масс объекта.
- Вычисления инерционных характеристик.

**Hu моменты (HuMoments)** — это набор инвариантных моментов, разработанных Ху М. К., которые остаются неизменными при переводе, масштабировании и повороте изображения. Эти моменты применяются для описания формы и используются в задачах распознавания объектов.

#### 2. Профили изображения

**Вертикальный профиль** — это сумма пикселей в каждом ряду изображения. Он помогает понять вертикальное распределение интенсивности пикселей в изображении.

Формула для вычисления вертикального профиля:

\[ V(y) = \sum_{x} I(x, y) \]

где \( V(y) \) — значение вертикального профиля на \( y \)-й строке, \( I(x, y) \) — интенсивность пикселя в точке \((x, y)\).

**Горизонтальный профиль** — это сумма пикселей в каждом столбце изображения. Он помогает понять горизонтальное распределение интенсивности пикселей в изображении.

Формула для вычисления горизонтального профиля:

\[ H(x) = \sum_{y} I(x, y) \]

где \( H(x) \) — значение горизонтального профиля на \( x \)-й колонке, \( I(x, y) \) — интенсивность пикселя в точке \((x, y)\).

#### 3. Фурье-дескрипторы

**Дескрипторы Фурье** — это коэффициенты преобразования Фурье, которые используются для описания формы контура объекта. Они позволяют сравнивать формы объектов, независимо от их положения, масштаба и ориентации.

Процесс вычисления Фурье-дескрипторов включает следующие шаги:
1. Представление контура объекта в виде комплексной функции.
2. Применение быстрого преобразования Фурье (FFT).
3. Нормализация дескрипторов для обеспечения инвариантности к масштабу, вращению и сдвигу.

Формула для вычисления дескрипторов Фурье:

\[ S(k) = \sum_{n=0}^{N-1} s(n) e^{-i \frac{2 \pi k n}{N}} \]

где \( S(k) \) — \( k \)-й дескриптор Фурье, \( s(n) \) — координата \( n \)-й точки контура, \( N \) — общее количество точек на контуре.

#### 4. Геометрические и статистические признаки

**Площадь (area)** — это количество пикселей внутри контура объекта. Она важна для оценки размера объекта.

Формула для вычисления площади:

\[ \text{area} = m_{00} \]

где \( m_{00} \) — нулевой момент изображения.

**Центр тяжести (centroid)** — это точка, в которой сосредоточена вся масса объекта. Вычисляется по формулам:

\[ x_c = \frac{m_{10}}{m_{00}}, \quad y_c = \frac{m_{01}}{m_{00}} \]

где \( m_{10} \) и \( m_{01} \) — моменты первого порядка.

**Ориентация (angle)** — угол, под которым ориентирован объект относительно осей координат. Вычисляется из ковариационной матрицы:

\[ \text{angle} = \frac{1}{2} \arctan\left(\frac{2 \cdot \text{cov}(x, y)}{\text{var}(x) - \text{var}(y)}\right) \]

где \( \text{cov}(x, y) \) — ковариация координат \( x \) и \( y \), \( \text{var}(x) \) и \( \text{var}(y) \) — дисперсии координат \( x \) и \( y \).

**Эксцентриситет (eccentricity)** — мера отклонения формы объекта от круга. Вычисляется из ковариационной матрицы:

\[ \text{eccentricity} = \sqrt{1 - \frac{\lambda_2}{\lambda_1}} \]

где \( \lambda_1 \) и \( \lambda_2 \) — собственные значения ковариационной матрицы.

**Рациональность формы (Rc)** — это отношение площади к квадрату периметра объекта. 

Формула для расчета:

\[ Rc = \frac{4 \pi \cdot \text{area}}{\text{perimeter}^2} \]

где \( \text{area} \) — площадь объекта, \( \text{perimeter} \) — периметр объекта.

**Отношение максимального диаметра к периметру (D/P)** — это отношение максимального диаметра объекта к его периметру.

Формула для расчета:

\[ D/P = \frac{\text{max\_diameter}}{\text{perimeter}} \]

где \( \text{max\_diameter} \) — максимальный диаметр объекта, \( \text{perimeter} \) — периметр объекта.

### Масштабирование данных с использованием RobustScaler

Масштабирование данных является важным этапом предварительной обработки, который помогает улучшить производительность алгоритмов машинного обучения. RobustScaler особенно полезен в случаях, когда данные содержат выбросы, так как он использует медиану и интерквартильный размах для масштабирования, что делает его устойчивым к аномальным значениям.

RobustScaler масштабирует признаки так, чтобы медиана каждого признака была равна нулю, а интерквартильный размах (разница между 75-м и 25-м процентилями) — равен единице. Формулы для масштабирования данных с использованием RobustScaler следующие:

Для каждого признака \( x \) рассчитываем медиану \( Q_2 \) и интерквартильный размах \( IQR = Q_3 - Q_1 \), где \( Q_1 \) — это 25-й перцентиль, а \( Q_3 \) — это 75-й перцентиль. Преобразованный признак \( x' \) вычисляется как:

\[ x' = \frac{x - Q_2}{IQR} \]

где:
- \( x \) — исходное значение признака,
- \( Q_2 \) — медиана признака,
- \( IQR \) — интерквартильный размах признака.

### Пример применения RobustScaler

Пусть у нас есть набор признаков \( x_1, x_2, \ldots, x_n \) для одного из сегментов изображения. Мы сначала вычисляем медиану \( Q_2 \) и интерквартильный размах \( IQR \) для каждого признака. Затем, используя вышеуказанную формулу, преобразуем каждый признак \( x \) в \( x' \).

Этот процесс помогает нормализовать данные, уменьшая влияние выбросов и делая признаки более сопоставимыми между собой, что в свою очередь улучшает обучение модели.

### Логистическая регрессия в классификации рукописных сегментов

Логистическая регрессия — это метод машинного обучения, который используется для решения задач бинарной классификации. Целью логистической регрессии является предсказание вероятности принадлежности объекта к одному из двух классов на основе одного или нескольких предикторов (признаков). Основным компонентом логистической регрессии является логистическая функция (сигмоида), которая преобразует линейную комбинацию признаков в вероятность:

\[
P(y=1|X) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X_1 + \cdots + \beta_n X_n)}}
\]

где \( P(y=1|X) \) — вероятность принадлежности к классу 1, \( \beta_0, \beta_1, \ldots, \beta_n \) — параметры модели (веса), и \( X_1, \ldots, X_n \) — входные признаки.

Для того чтобы логистическая регрессия могла эффективно выполнять классификацию, модель должна быть сначала обучена на размеченных данных. В нашем исследовании обучение модели проводится на заранее размеченных экспертами рукописях, которые были вручную сегментированы и классифицированы. Этот процесс позволяет подобрать оптимальные веса для каждого признака, необходимые для адекватной классификации новых данных.

Так как у нас имеется большое количество различных символов, мы последовательно применяем логистическую регрессию для каждого сегмента. В результате этого процесса мы получаем набор чисел, представляющих вероятность принадлежности к каждому из классов. Для определения окончательного класса каждого сегмента мы сравниваем все полученные вероятности и выбираем класс с наибольшей вероятностью.

Таким образом, процесс классификации заключается в следующем: для каждого сегмента вычисляются вероятности его принадлежности ко всем возможным классам с помощью заранее обученной модели логистической регрессии, а затем на основе максимальной вероятности принимается решение о принадлежности сегмента к конкретному классу.
